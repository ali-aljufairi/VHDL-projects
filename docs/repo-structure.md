# Repo structure (how to navigate)

## Start here
If you’re new: read **docs/getting-started.md** first.

## Top-level folders
- **Projects/**
  - Main learning content.
  - Many folders contain a testbench (`tb_*.vhd`).
  - Best place to start.

- **LABS/**
  - Lab exercises/submissions.
  - Some are rough/"as submitted".

- **Codes to learn from/**
  - Older material: exam solutions + miscellaneous references.
  - Kept for learning, but less consistent.

## Guiding principle
I’m not deleting anything, just **adding signposts** (READMEs and docs) so beginners can find a path.

If you want a cleaner layout later, we can gradually migrate content into a structure like:
- `examples/01-combinational/`
- `examples/02-sequential/`
- `examples/03-fsm/`
…while keeping the original folders intact.
